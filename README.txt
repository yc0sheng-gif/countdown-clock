大型時鐘倒數計時器 PWA
====================

功能
- 手機時鐘大小可在設定內選擇 60%、70%、80%、90% 或全螢幕；百分比代表長方形時鐘佔手機視窗的面積。
- 四組時間皆為空白起始，可自由編輯時、分、秒。長按任一組時間框兩秒，只編輯該組；短按已設定的時間即可開始倒數。
- 時鐘內含四組時間、開始/暫停、重來、結束、全螢幕、音效設定及時間編輯。
- 設定選單內提供 8 種鮮亮底色；時鐘與設定鍵、三個操作鍵、四個時間框共用同一條填色邊界。倒數色區尚未到達某個框時該框維持填滿，邊界進入後框內填色才逐漸減少。
- 四組時間框與三個操作鍵採白色外框，框內會跟隨所選時鐘底色變化；文字和符號顏色可在設定中用 8 個色塊選擇（淺淺灰已改為深灰）。
- 設定選單可分別選擇大時鐘數字、四組時間數字、操作鍵文字/符號及設定鍵符號的五種字級：小、標準、稍大、更大、大。
- 倒數進行中主時鐘與目前使用的時間框顏色可從設定內選擇時鐘底色的 8 種顏色。
- 設定鍵使用與操作鍵相同的底色、文字顏色及白色外框；操作鍵高度比上一版增加 25%，寬度維持不變。
- 時鐘數字、提示文字與按鍵文字可調整大小。
- 每秒滴答聲可開關與調整音量，輸出音量已提升 20%；最大音量使用柔和波形並限制峰值，以保持清晰並降低削波失真。
- 提供 20 種到時鈴聲，其中新增 8 種急促鬧鐘風格；可在鈴聲種類下方試聽、調整音量並選擇播放一次、延長或重複 5 次。
- 到時鈴聲輸出音量已提升 20%。
- 按下任何畫面按鈕或鍵盤按鍵，都會立即停止到時鈴聲並取消後續重複播放。
- 加大時鐘數字、狀態指示、設定文字、符號與按鍵，並加寬按鍵觸控區域。
- 設定儲存在目前瀏覽器/裝置本機。支援 PWA 安裝、離線快取與螢幕常亮（依瀏覽器支援情況）。
- 設定選單若未按「完成」而關閉或按 Esc，若有變更會先詢問是否儲存。

部署
1. 將 index.html、style.css、app.js、manifest.webmanifest、sw.js、icon.svg 及 README.txt 上傳到網站根目錄。
2. 以 HTTPS 網站開啟（例如 GitHub Pages），即可使用離線快取與 PWA 安裝功能。

使用
1. 長按任一時間框 1 秒，設定該組的時、分、秒；未設定組會顯示「--:--」。編輯畫面中的時、分、秒欄位等寬。「重置」會將三欄清為 0，按「儲存」後套用。
2. 短按已設定的時間框即可開始；使用中可暫停、繼續、重來或結束。
3. 右上角齒輪可調整時鐘大小、滴答聲、20 種到時鈴聲及 8 種時鐘底色，也可選擇按鍵文字/符號顏色。
4. 開始鍵文字為兩個字時，會在兩字中間留一格。
5. 瀏覽器通常需要先由使用者互動，才會允許播放聲音。

提醒
- iOS、Android 與桌面瀏覽器對全螢幕、螢幕常亮和 PWA 安裝的支援程度不同。
- Web Audio 即時產生滴答聲和鈴聲，不需要另外放置音訊檔。
